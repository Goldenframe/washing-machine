# Стиральная машина

Интерактивная стиральная машина на JavaScript и Tailwind CSS. Добавьте бельё и гель, затем нажмите «Начать стирку». Пока барабан вращается, в блоке «Статус» отображается текущий этап. Если забыть бельё или гель, машинка подскажет, чего не хватает.

## Как запустить

Откройте `index.html` в браузере. Всё необходимое уже есть в репозитории.

## Как пересобрать стили

Эти команды нужны после изменения классов Tailwind.

```sh
npm ci
npm run build
```
